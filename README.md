# Power BI Business Sales Dashboard

A dynamic and interactive Power BI dashboard designed to analyze business sales performance, shipment trends, product insights, and profit analysis. This dashboard helps users monitor KPIs, compare yearly performance, and identify top-performing products and salespersons.

---

# Short Description / Purpose

The Power BI Business Sales Dashboard is a visually interactive analytics report created to explore and monitor sales data efficiently.

The dashboard focuses on:
- Sales & Profit Analysis
- Shipment Tracking
- Product Performance
- Geographic Sales Distribution
- Salesperson Performance

This project is useful for:
- Business Analysts
- Data Analysts
- Sales Teams
- Beginners learning Power BI
- Portfolio & Resume Projects

---

# Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 Power BI Desktop – Main data visualization platform used for dashboard creation.
- 📂 Power Query – Used for data cleaning and transformation.
- 🧠 DAX (Data Analysis Expressions) – Used for calculated columns, KPIs, and measures.
- 🔗 Data Modeling – Relationships between sales, products, shipments, and geography tables.

---

# Data Source

The dataset used in this project contains business sales information including:

- Product sales
- Shipment counts
- Profit values
- Salesperson details
- Geographic sales distribution
- Monthly sales trends

The data was used for learning and dashboard practice purposes.

---

# Features / Highlights
- Interactive sales and profit analysis dashboard
- Year-over-Year (CY vs PY) sales comparison
- KPI cards for quick business overview
- Shipment trend and box distribution analysis
- Top-performing products visualization
- Geographic sales distribution insights
- Salesperson performance tracking
- Product-wise profit analysis
- Dynamic filters for better data exploration
